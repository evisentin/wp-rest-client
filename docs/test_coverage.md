# Test Coverage

The project is continuously analyzed with **JaCoCo** to measure unit test coverage.

The report below contains:

- Overall line, branch, and instruction coverage
- Package and class-level metrics
- Drill-down navigation to individual source files
- Highlighted covered and uncovered code

The report is generated automatically as part of the build and reflects the current published version of the project.
